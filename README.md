# Dashboard E-Commerce / Manajemen Produk Toko Online

Aplikasi Dashboard Admin Interaktif berbasis Web yang menerapkan fitur CRUD (Create, Read, Update, Delete) secara client-side.
Dibuat untuk memenuhi tugas Responsi 1 Pemrograman Fullstack - Universitas 'Aisyiyah Yogyakarta.

## Cakupan Teknologi

- React 19 (Vite)
- Bootstrap 5 & Bootstrap Icons
- jQuery
- HTML5 & CSS3

## Fitur Utama

- **Create**: Menambah produk baru melalui Modal Form.
- **Read**: Menampilkan daftar katalog produk, stok, harga, diskon, dan ringkasan metrik.
- **Update**: Mengubah data produk yang ada.
- **Delete**: Menghapus produk dari daftar etalase.
- **Filter**: Pencarian reaktif berdasarkan nama produk dan kategori.
